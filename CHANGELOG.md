## [1.0.0] - 2026-09-01

### Added

- MCP-сервер для Elba Public API через `stdio`.
- Доступ ко всем операциям из OpenAPI-схемы.
- Проверка разрешённых маршрутов и безопасная передача API-ключа.
- Инструменты просмотра операций и списка организаций.
- Русская инструкция по установке и настройке.
